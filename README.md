## ✨ Features

- **Minimalist Design** — Clean and modern visual interface.
- **Responsive Layout** — Optimized for desktop, tablet and mobile devices.
- **Hero Section** — Personal introduction and professional presentation.
- **Projects Showcase** — Display of selected projects with previews and live demo links.
- **About Section** — Introduction, development approach and technical skills.
- **Contact Section** — Contact form interface and direct contact information.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Build for production

```bash
npm run build
```
